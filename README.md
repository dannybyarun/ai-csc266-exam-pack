## 🔥 If you learn only 3 things (7/7 papers asked these)

1. **Search traces** — UCS=g · Greedy=h · A*=g+h ("Gone + Hope"), optimal iff h admissible
2. **FOPL → CNF → Resolution** — negate goal → cancel pairs → □ = proved ∎
3. **ANN** — y = f(Σwx+b) · Hebb Δw=x·t (OR: w₁=2,w₂=2,b=2) · backprop: error flows backward
